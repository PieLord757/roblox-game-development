# Banned list (shared by every game)

**Anything the user says looks AI-made goes here immediately**, with a short generic reason (what makes it read as AI-made). Keep this file generic: no game names, no dates, no user names. If the audit reviewer catches the same tell in two different games, add it too. Only the user removes entries.

Studio-specific additions (tells tied to the studio's own games or house rules) may live in `studio-profile.md` at the project root instead. Read it if it exists; its bans count exactly like the ones here.

## UI and art
| Banned | Why |
|---|---|
| "Futuristic" display fonts: Michroma, Orbitron, Audiowide, Exo, Rajdhani, Oxanium, Russo One | The fonts every generator reaches for to say "sci-fi"; they read as a template, not a world |
| Roboto Mono or any monospace font used as a "tech" look | A lazy shortcut for "technical"; it rarely fits the setting and reads as placeholder |
| Thin rounded progress bars, especially a label stacked over a number over a bar | The default generated HUD element; it carries no information about the game's world |
| Status text like READY, SYSTEM ONLINE, INITIALIZING, ACCESS GRANTED, LOADING ASSETS... | Generic computer-boot flavor text that every AI-made sci-fi UI uses |
| Glowing cyan or teal on dark navy as the main look; neon outlines on everything | Classic generated sci-fi look |
| Gradient buttons with drop shadows; glassmorphism panels; every panel the same rounded rectangle | Template UI |
| Emoji in game UI, titles, or buttons | Reads as cheap and kid-targeted |
| Default Roblox fonts on headings (Gotham/Builder Sans used without thought), default skybox, grey baseplate, untextured parts | Placeholder look |
| Hex-grid or circuit-board background patterns; floating HUD brackets in the corners | Generic sci-fi filler |
| Store art in the glossy, over-smooth AI-image style, or text in thumbnails the game doesn't use | First impression on Discover |

## Writing
| Banned | Why |
|---|---|
| Words: testament, tapestry, delve, embark, unravel, realm, beacon, symphony, "whispers of", "echoes of", "a dance of", "in the heart of" | Top AI-writing tells |
| Names: Elara, Kael, Lyra, Nova, Seraphina, Orion, "Dr. ___ Voss", "Kai" as the default hero | The names every model picks |
| **Em dashes (—), anywhere.** In-game text, UI, dialogue, store page, descriptions, and anything players read. Use a comma, period, colon, or parentheses instead | The single most recognizable AI-writing tell |
| "It's not X, it's Y" lines; three-item lists everywhere | AI sentence patterns |
| Characters explaining the plot to each other; villains announcing their plan | Exposition dumps |
| Ending on a neat moral or lesson; everyone sounding equally articulate | Flat, chatbot voice |
| Tutorial text that reads like documentation ("Press E to interact with the interactive object") | Lifeless instruction copy |
